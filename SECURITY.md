# Security

Thanks for helping keep libnudget projects safe.

To report a security vulnerability, please do not open a public issue.
Report it privately instead:

- Open a private advisory on GitHub:
  https://github.com/libnudget/release-notes/security/advisories/new
- Or email the maintainers via the contact details in
  https://libnudget.github.io/.well-known/security.txt

We will acknowledge reports within 48 hours and coordinate disclosure.
