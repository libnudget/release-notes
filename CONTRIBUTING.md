# Contributing

Thanks for your interest in this project.

It is in early development, so please open an issue to discuss any changes
before submitting a pull request.

## Getting started

1. Fork the repository.
2. Create a branch.
3. Make your changes.
4. Open a pull request.

## Guidelines

- Keep the change small and focused on one problem.
- Keep documentation up to date.
- Match the project's MIT license and existing code style.

See the [libnudget website](https://libnudget.github.io) for the project's
philosophy and standards.
